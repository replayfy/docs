---
title: "Identify users"
description: "Attach a known user to the session so replays, funnels, and filters are searchable by who did what."
---

Call `identify` once you know who the user is — typically right after login. Every
session before and after links to that user, and earlier anonymous sessions are
associated retroactively. Pass a stable `distinctId` (your own user id) plus any
traits you want to filter and segment on (`email`, `name`, `plan`, …).

<Note>Web snippets assume `replay` is the value returned by `initReplay()`. With the CDN `<script>` build, call `Replayfy.identify(...)` instead.</Note>

<Tabs>
  <Tab title="Web">
    ```ts
    replay.identify("user_123", { email: "ada@example.com", plan: "pro" });
    ```
  </Tab>
  <Tab title="iOS">
    ```swift
    Replay.identify("user_123", properties: ["email": "ada@example.com", "plan": "pro"])
    ```
  </Tab>
  <Tab title="Android">
    ```kotlin
    Replay.identify("user_123", mapOf("email" to "ada@example.com", "plan" to "pro"))
    ```
  </Tab>
  <Tab title="React Native">
    ```tsx
    Replay.identify("user_123", { email: "ada@example.com", plan: "pro" });
    ```
  </Tab>
  <Tab title="Flutter">
    ```dart
    Replay.identify("user_123", properties: {"email": "ada@example.com", "plan": "pro"});
    ```
  </Tab>
</Tabs>

<Tip>`email`, `name`, `plan`, and `picture` are promoted to first-class user fields on the dashboard — filterable, and `picture` renders as the user's avatar. Any other trait is kept as searchable custom metadata.</Tip>

<Tip>
**Avatar** — set `picture` (or its alias `avatar`) to a public **https** image URL to show the user's avatar on the recording header and the Users list. It works as a top-level trait or nested inside `customProps`, so every SDK supports it today with no upgrade; non-URL values are ignored.
</Tip>

```ts
replay.identify("user_123", { email: "ada@example.com", picture: "https://cdn.example.com/u/123.png" });
// or, from any SDK, via custom properties:
replay.identify("user_123", { customProps: { avatar: "https://cdn.example.com/u/123.png" } });
```
