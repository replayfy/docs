## Report a security issue

If you've found a vulnerability, please **do not** open a public issue. Email
**security@replayfy.app** with the details and we'll respond quickly.

<Warning>
  Report security problems privately to **security@replayfy.app** — not on GitHub or
  in a support ticket — so we can fix them before they're disclosed.
</Warning>

See the `SECURITY.md` in any of our SDK repositories for the full policy and what to
include in a report.

## Status & updates

For the latest SDK versions and release notes, check the **Releases** tab on each
SDK's GitHub repository. New capture features and dashboard settings roll out
continuously — and because SDK settings are fetched from the dashboard at startup,
most improvements reach you without shipping a new build.
