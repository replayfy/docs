---
title: "What is Replayfy?"
description: "Session replay, product analytics, and error monitoring for web and mobile — one SDK per platform."
---

Replayfy records what your users actually do — pixel-accurate session replays, taps
and clicks, screen navigation, network activity, console logs, crashes, and
performance vitals — and streams it to your dashboard so you can watch real
sessions, build funnels, and debug errors from the exact moment they happened.

Drop in one SDK per platform and you're recording in under two minutes.

## How it works

Each SDK captures on-device, batches efficiently, and streams to the Replayfy
ingest endpoint. Recording, tap capture, screen detection, crash handling, and
performance monitoring all start from a single `init` / `start` call — no manual
wiring.

Dashboard configuration overrides the values you set in code, so you can tune
capture (masking, sampling, what to record) without shipping a new app build.
